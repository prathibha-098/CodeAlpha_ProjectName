# CodeAlpha Task 3 — Data Visualization

## Requirement covered
The brief asks interns to transform raw data into charts/graphs/dashboards, use visualization tools, reveal insights clearly, and create data stories supporting decisions.

## Stack
Streamlit + Python + Pandas + NumPy + Matplotlib.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload a CSV. The app detects date-like, numeric and categorical columns and creates a dashboard.

## Visualizations
- Time-series trend
- Category comparison
- Histogram/distribution
- Numeric scatter relationship
- KPI metric
