# CodeAlpha Task 2 — Exploratory Data Analysis

## Requirement covered
The brief asks for meaningful questions, data structure/type exploration, trends/patterns/anomalies, statistical validation and identification of data issues.

## Stack
Streamlit + Python + Pandas + NumPy + Matplotlib.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload any CSV or use the included built-in demo data.

## Methods
- Shape, dtypes and unique-value inspection
- Descriptive statistics
- Missing-value and duplicate checks
- IQR-based potential outlier detection
- Scatter plot and Pearson correlation for numeric variables
